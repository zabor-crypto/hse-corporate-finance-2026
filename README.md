# Corporate Finance Learning OS · 0.3.0 Beta

Независимый учебник и практикум по корпоративным финансам. Не официальный продукт НИУ ВШЭ; преподавательское согласование не заявлено.

Площадка beta: https://zabor-crypto.github.io/hse-corporate-finance-2026/ — доступна после успешного guarded Pages deployment. Фактический статус и точный SHA смотрите в [GitHub Actions](https://github.com/zabor-crypto/hse-corporate-finance-2026/actions), footer приложения и `build-info.json`.

## Учебная область

Доступны шесть полных уроков: T3-01 (отчётность), T3-03 (NWC и денежные потоки), T3-05 (рентабельность), T3-06 (рычаг), T3-07 (ликвидность и цикл), T3-08 (DuPont). В корпусе 37 разделов, 65 разобранных примеров, 43 recall и 36 формул с переменными, единицами, выводом и ограничениями.

30 фиксированных задач и 32 воспроизводимых варианта четырёх моделей не означают 62 разных компетенции. Study раскрывает шаги; Practice запрашивает конечные результаты и отмечает использование помощи; Exam скрывает название темы, метод и промежуточные этапы до сдачи. Числовой objectiveScore и reasoningStatus разделены; свободный текст не получает семантического балла. outcomeStatus остаётся NOT_PROVEN.

Самостоятельные главы T3-02/04, полные T3-09/10/11 и трёхлетняя модель 3.7 ещё не выпущены. Ограниченный DDM-мост не завершает главу 09. Внутреннее экспертное review и агентная симуляция не являются исследованием реальных студентов или гарантией результата на контрольной.

## Прогресс и данные

История, единицы ответа, черновики и отметки чтения хранятся локально в браузере. Аккаунта, облачной синхронизации и серверного backup нет. Экспортируйте JSON на странице «Мой прогресс»; перенос на другое устройство, другой браузер или другой origin выполняется экспортом и импортом. Данные localhost не появляются на Pages автоматически. При импорте сохраняется прежняя история; старые баллы не пересчитываются задним числом.

## Локальная проверка

Node 26.6.0 зафиксирован в `.nvmrc` и CI; зависимости — в package-lock.json.

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm test
npm run test:financial
npm run review:storage
npm run build
npm run test:e2e
npm run audit:artifact
npm run audit:public -- --strict
```

`npm run dev` запускает локальный Vite URL с путём `/hse-corporate-finance-2026/`. E2E использует выделенные порты 5182/5183, отдельные синтетические профили и Chrome/Chromium плюс WebKit. Нативные тесты, Ubuntu CI и hosted smoke имеют разные области доказательств.

## Чистая публичная история

Этот repository имеет самостоятельную очищенную историю. `PUBLIC_SOURCE_MANIFEST.json` — неизменяемая запись исходного импорта из проверенного implementation checkpoint 5429d4f; это не текущий release approval и не манифест будущих редакций. Изменения beta ограничены лицензиями, release-инфраструктурой и документацией; финансовый корпус и правила оценивания заморожены.

Private Git history и private evidence не являются upstream для merge или push сюда. Обновления переносятся только проверенным экспортом разрешённых файлов с manifest, отдельным review, текущими gates и exact-SHA deployment. Owner authorization для beta уже получен; он не отменяет ни один gate. Новый release требует соответствующего разрешения владельца.
