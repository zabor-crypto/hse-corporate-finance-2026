# Corporate Finance Learning OS

Независимый учебник и практикум по корпоративным финансам. Не официальный продукт НИУ ВШЭ; преподавательское согласование и доказанное освоение студентами не заявлены.

**Версия исходников — v0.4.0.** [Открыть учебник](https://zabor-crypto.github.io/hse-corporate-finance-2026/). Фактически размещённые версия и commit доступны в [build-info.json](https://zabor-crypto.github.io/hse-corporate-finance-2026/build-info.json), состояние проверок — в [GitHub Actions](https://github.com/zabor-crypto/hse-corporate-finance-2026/actions). Разрешение владельца действует после прохождения release gates; эти исходники сами по себе не доказывают успешный deployment. [Статус и ограничения](docs/PROJECT_STATUS.md), [выпуск v0.4.0](docs/PUBLIC_RELEASE_V0_4_0.md).

## Учебная область v0.4.0

Все 11 глав темы3: отчётность, затраты/P&L, NWC, денежные потоки, доходность, рычаг, ликвидность, DuPont/консолидация, дивиденды/рост/DDM, бюджеты/отклонения и условная трёхлетняя модель. Пять новых глав добавлены к шести прежним, которые отредактированы точечно. Преподавательские задачи3.1–3.9 сопоставлены с самостоятельными авторскими задачами; недостающие данные оригинала явно отделены от допущений учебного сценария.

Study раскрывает шаги и объяснения. Independent Practice запрашивает конечные результаты на других данных и регистрирует помощь. Три короткие смешанные контрольные, отдельный вариант из шести заданий «Короткая практика · коэффициенты и взаимосвязи», широкий тест40 вопросов и две интеграционные расчётные контрольные собираются из проверенного пула с сохранением точного состава, версий, seed и семейств. Это тренировочные симуляции: фотографий реальной КР3 нет, её официальный формат и темп не подтверждены.

Количество записей и seeded-вариантов не равно количеству навыков. `objectiveScore` оценивает числовые ответы и выбор вариантов; свободный текст не получает смыслового автоматического балла. Объяснение проверяет студент или человек, результат обучения остаётся `NOT_PROVEN`.

[Архитектура расширяемой программы](docs/CURRICULUM_REGISTRY.md) поддерживает новые темы без фиксированного будущего syllabus. Синтетическая тема4 есть только в тестах.

## Прогресс и данные

История, единицы ответа, черновики и отметки чтения хранятся локально в браузере. Аккаунта, облачной синхронизации и серверного backup нет. Экспортируйте JSON на странице «Мой прогресс»; перенос на другое устройство, другой браузер или другой origin выполняется экспортом и импортом. Данные localhost не появляются на Pages автоматически. При импорте сохраняется прежняя история; старые баллы не пересчитываются задним числом.

```sh
npm ci

npm test

npm run review:storage
npm run build

npm run test:e2e:c3
npx playwright test --config playwright.c3-delta-qa.config.ts
```

## История, источники и выпуск

Репозиторий имеет самостоятельную очищенную историю. [PUBLIC_SOURCE_MANIFEST.json](PUBLIC_SOURCE_MANIFEST.json) — неизменённое историческое свидетельство первого импорта, включая его прежние BLOCKED/UNKNOWN-поля; это не текущее состояние выпуска. [PUBLIC_RELEASE_DELTA_MANIFEST.json](PUBLIC_RELEASE_DELTA_MANIFEST.json) отдельно описывает разрешённый перенос принятого содержания в v0.4.0. Приватная Git-история не является upstream этого кандидата. При подготовке публичного перехода проверяются только чистая ветка кандидата, её достижимая история, фактические bytes и exact-SHA authorization.

NordicTech/«Задание к семинару3.xlsx» — `SOURCE_AVAILABLE_PRIVATE / CALIBRATED_WITH_STATED_LIMITS` (SHA-256 `541f041a94b5f8a71cad57aa9298e0da33e39581bfca87fbf93b5a167585654c`). Подлинные байты восстановлены из частного handoff; калибровка сохранена отдельно от исходников. Распределение общей D&A между функциями не задано, а одна налоговая строка не совпадает с точными20%; эти ограничения раскрыты без подгонки. Лекции и семинар проверены по частным оригиналам; они и workbook не входят в публичные исходники или Pages artifact. Частный аудитный ZIP не является deployment artifact. Внешние пояснения IAS7/IFRS18 ссылаются на публичные обзоры IFRS Foundation и отделены от преподавательских конвенций.

В v0.4.0 KaTeX зафиксирован на0.18.2 после отдельной проверки совместимости и математики; зависимости устанавливаются из lockfile. Формулы скомпилированы из проверенного авторского корпуса, пользовательский LaTeX не поддерживается.

Публикационные скрипты и CI сохраняют отдельные gates. Владелец разрешил публичную release-ветку, PR, merge и guarded deployment v0.4.0 после проверок точных SHA. Историческое разрешение v0.3.0 сохранено отдельно; изменение account-wide email privacy не разрешено. Локальные тесты macOS не выдаются за новую Ubuntu CI или проверку физических телефонов.
