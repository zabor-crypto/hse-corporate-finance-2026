# Авторизация выпуска 0.3.0 Beta

Владелец явно разрешил создание публичного `zabor-crypto/hse-corporate-finance-2026`, MIT для собственного кода, CC BY 4.0 для оригинального учебного текста, commit/push/merge, настройку Actions/Pages/environment/variables и первый guarded deployment после успешных gates. Хеш исходного разрешения сохранён в publication-policy.json; приватный документ не публикуется.

Разрешение распространяется только на оригинальные материалы с правом распространения. Teacher PDFs, фотографии, private evidence/history, персональные данные и чужие неразрешённые тексты исключены. Наличие библиографической ссылки не предоставляет лицензию на исходный документ.

Точный release SHA определяется после freeze и независимого review. Для dispatch обязательны main, release_candidate_sha==github.sha, owner_approved=true, PUBLIC_RELEASE_ENABLED=true, успешная verify job, strict public audit и exact verified artifact binding. Разрешение владельца действует на этот проверенный beta-кандидат и не разрешает обход условий.

Операционные статусы CI и Pages читаются из GitHub Actions. Пока успешный deployment и hosted QA не подтверждены, LIVE не заявляется. Лицензии не означают преподавательского одобрения или доказательства учебного эффекта.
