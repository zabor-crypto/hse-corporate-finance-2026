# Решения владельца перед публичным выпуском

PUBLIC_RELEASE: **BLOCKED**. Этот транш разрешает локальную подготовку, проверку, коммиты и отдельный очищенный public-source snapshot. Он не разрешает создание remote, push, merge в main или deployment. Эти переходы не выполнялись.

| Вопрос                                        | Текущее состояние               | Нужно для следующего перехода                                         |
| --------------------------------------------- | ------------------------------- | --------------------------------------------------------------------- |
| Лицензия оригинального кода                   | UNDECIDED / UNKNOWN             | Выбрать лицензию и её точный текст                                    |
| Лицензия авторского учебного корпуса          | UNDECIDED / UNKNOWN             | Отдельное решение владельца                                           |
| Права на распространение производного корпуса | UNKNOWN                         | Подтвердить допустимую область; PDF преподавателя не распространяются |
| Публичный источник                            | Отдельный локальный snapshot    | Проверить manifest и независимый аудит этого snapshot                 |
| Каноническая private-история                  | Сохранена; содержит local paths | Не публиковать её; не переписывать в рамках этого задания             |
| GitHub repository / Pages settings            | NOT_CHECKED                     | Проверить доступ, план, environment, защиту main и destination        |
| Разрешение public release                     | Не дано                         | Явно разрешить конкретный SHA и целевой repository                    |
| Teacher alignment                             | Не подтверждён преподавателем   | Экспертный агент не заменяет преподавателя                            |

Кандидаты для решения, не установленный выбор: MIT / Apache-2.0 для кода; CC BY 4.0 / CC BY-SA 4.0 для оригинального учебного текста. Совместимость с правами на исходные материалы требует отдельного решения владельца. publication-policy.json остаётся UNDECIDED, redistributionApproved=false.

Workflow привязан к точному Node 26.6.0 и полным SHA действий. Публичная мутация требует owner dispatch, main, exact SHA, отдельный PUBLIC_RELEASE_ENABLED, PASS истории/прав и совпадение проверенного артефакта. Локальная проверка не доказывает, что GitHub CI, deployment или права на распространение одобрены. Не выполнялась пробная deployment-команда для проверки блокировки.
