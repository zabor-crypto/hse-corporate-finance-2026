## Учебный маршрут

Главная выделяет текущую тему и одно следующее действие. Дата и официальный формат ближайшей контрольной не выдумываются. Практика начинается с выбранного шага; полный каталог доступен отдельно. Study раскрывает подсказки, самостоятельная практика отмечает обращение к помощи, mock раскрывает разбор после отправки. Письменное объяснение выбора можно добавить по желанию; программа не присваивает ему смысловой балл.

T3 использует отдельную версионированную проекцию `src/pedagogy/t3-path.ts`: экономический вопрос, механизм, формула с базой и единицами, один существующий числовой пример, самостоятельное применение и самопроверка. Все 11 исходных уроков, 51 формула, 124 старых задания и 7 старых blueprints сохраняют полные объекты и версии. Все 70 прежних якорей открывают полный справочник автоматически; дополнительные примеры и модели загружаются при его раскрытии. Новый `T3-HV01` отдельно проверяет горизонтальный и вертикальный анализ. Число основных блоков не означает число независимых навыков: два блока прямого/косвенного перехода к потокам используют один интегрированный checkpoint.

T4 содержит пять последовательных уроков: релевантный поток; NPV/PI и временная стоимость; границы IRR/MIRR и окупаемости; сравнение проектов/повтор/замена; инфляция, налог, NWC и финансирование. Двенадцать авторских аналогов семинара используют новые условия и явно объявленные предпосылки. Ещё четыре коротких случая проверяют релевантность, заёмный и смешанный потоки, точку Фишера и выбор. Два mock — авторские тренировки, их формат и лимиты времени преподавателем не подтверждены.

## Предметные границы

- Проектный поток до финансирования отделён от кредита, процентов, погашения и остатка cash. Налоговый эффект процентов при кассовом моделировании задаётся явно.
- PI различает валовые инвестиционные строки и разбиение уже свёрнутого потока по знакам. MIRR использует разные ставки финансирования и реинвестирования; конвенция свёртки объявляется отдельно.
- У растущей ренты первое поступление имеет собственную дату; terminal value относится к предыдущей дате, требуется `r > g`. Разовый возврат NWC не интерполируется внутри года для PB/DPB.
- IRR возвращает явный статус: один, несколько, отсутствие, тождественная неопределённость или численная неопределённость. Заёмный поток не оценивается обычным инвестиционным правилом. Почти кратные корни и крайние масштабы могут требовать высокоточного независимого решения.
- Реальные и номинальные потоки согласуются со ставками. Сравнение EAA/цепей/срока замены предполагает оговорённую сопоставимость услуги и повторение. EAA/EAC обозначают постоянную годовую сумму; единицы платежа выбираются отдельно.
- Оригиналы семинара 4.7/4.8 и часть баз задачи 4.11 не дают единственного численного ключа без предпосылок. Автопроверка относится к новым явно заданным авторским сценариям.
- В одном смешанном случае показаны два поля IRR: проверяются упорядоченные значения и NPV, а не самостоятельное обнаружение числа корней. Правильные числа, чтение и повтор знакомого задания не доказывают перенос.

Новые условия независимо решены до чтения авторских ключей и grading code. Отдельно проверены целые уроки, формулы, примеры и mock. Авторские проверки схемы и синтаксиса не подменяют независимую предметную приёмку. Поддерживающие исходные условия, независимые producers, точные проверенные версии и receipts находятся в частном аудитном пакете. Исходные преподавательские PDF в Git не включены.

## Архитектура и данные

`ModulePack` связывает typed content, реестр и конфигурацию маршрута. Экраны Home/Exam/LessonView получают активный pack; manifest и динамические loaders позволяют добавить следующую реальную тему без фиксированного будущего syllabus. Pure factory не импортирует T3 и не публикует неизвестные версии по умолчанию. Старые неполные маршруты exam/practice по-прежнему относятся к T3; квалифицированные маршруты выбирают модуль явно. Сохранённая контрольная другой темы открывается в своей теме либо явно архивируется.

Публичный формат экспорта и импорта остаётся schema1. `cflos.progress.v1` не перезаписывается миграцией: его точные исходные байты дополнительно сохраняются атомарно. Рабочая история хранится в IndexedDB с полными восстанавливаемыми snapshots и порядком записей; внутреннее объединение одинаковых снимков не удаляет попытки. CAS предотвращает молчаливое перетирание другой вкладкой. Конфликт требует явного решения, повреждённая основная копия не сбрасывается автоматически.

Черновик редактируется локально; небольшой синхронный журнал хранит исходные строки, включая `1.`, `1,`, `−`. Полная история не сериализуется на каждую клавишу. Отложенная запись и lifecycle flush дополняются восстановлением журнала; завершение асинхронной транзакции после закрытия вкладки не обещается. При явном восстановлении сохраняются прежние значения затронутых черновиков. Импорт подтверждается после transaction complete; ошибка импорта не скрывает новые текущие изменения. История отображается порциями по 25, JSON формируется при раскрытии.

Данные остаются на устройстве, без аккаунта, сервера или облачной резервной копии. Экспорт JSON нужен для другого браузера/origin и отдельного backup. Никакая проверка не использует реальные результаты студента.

## Воспроизводимость

```sh
npm ci
npm test
npm run review:storage
npm run build
npm run test:e2e
npm run test:e2e:c3
npx playwright test --config playwright.c3-delta-qa.config.ts
npx playwright test --config playwright.ppi.config.ts
npm run audit:artifact
npm run audit:public -- --strict
```

Точные команды, версии браузеров, fixtures, исходные наблюдения и before/after-замеры находятся в частном handoff. Ввод до правок уже укладывался в ориентир 100 мс: улучшение нельзя приписывать устранению несуществовавшего превышения. Показатели второго animation frame не являются измерением INP. Полные истории на 1000 попыток отдельно проверяются на ёмкость, импорт и экспорт; неудачный baseline не заменяется вымышленным временем. Автоматические проверки и агентская симуляция не являются испытанием на реальном студенте.
