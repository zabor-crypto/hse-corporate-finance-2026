# v0.5.0 Beta: подготовка к инвестиционному разделу

Версия исходников — 0.5.0. Владелец разрешил ограниченный выпуск после независимых финансовых проверок, точных local/Ubuntu CI gates и штатного guarded Pages workflow. Сам этот документ не утверждает, что deployment уже выполнен: фактические version/SHA находятся в [build-info.json](https://zabor-crypto.github.io/hse-corporate-finance-2026/build-info.json).

## Что изменилось для студента

| Проблема | Поведение версии 0.5.0 |
| --- | --- |
| После объяснения потока требовались ещё не разобранные показатели | После T4-01 — отдельная L2-задача на даты и релевантный поток. После T4-02 — NPV/валовой PI без IRR. Задания с налоговым мостом следуют после T4-05; IRR — после T4-03. |
| Общий тег приводил к слишком сложному повтору | Следующий случай ограничен конкретными навыками, сложностью и доступной учебной базой. Если подходящего нового случая нет — фрагмент урока и честный повтор прежнего. |
| MPI можно было спутать с процентом доходности | Компактный пример различает лекционный MPI, превышение MPI−1, ECF/EAA и обычный PI/IRR. Округлённые 17/23 из семинара не выдаются за точные входы. |
| Таймер и фильтр невиданных мешали тренировке | По умолчанию работа без ограничения времени. Добровольный авторский таймер не блокирует ввод; после reload выключается. При исчерпанном банке предлагается явно разрешить повтор. |
| Seed воспринимался как генератор новых задач | Для фиксированных составов прямо указано: номер воспроизводит сборку, не создаёт новые условия и может включать уже решённые задачи. |
| Отложенный фокус страницы мог опередить быстрый ввод | Если поле новой задачи уже получило фокус, переход больше не забирает его к заголовку. Запись черновика и схема хранения не менялись этим исправлением. |
| После независимой навигации оставалась кнопка возврата | Возврат привязан к конкретному переходу «задача → объяснение» и очищается при выходе из него. Возврат к результату сохраняет тему контрольной. |

## Финансовые границы

Две новые задачи и пример MPI решены независимым Fraction/Decimal-расчётом без функций приложения, до сравнения авторских ключей. Все прежние численные ключи T4, единицы, допуски и конечные самостоятельные ответы сохранены. Пять задач получили версию1.0.1 из-за исправления размещения/помощи; CORE-blueprint закрепляет актуальные версии. Прежние попытки и их snapshots не перепроверяются новым ключом.

У источника по MPI есть неоднозначность обозначения и округления. Сверка процентов семинара4.9 предполагает, что ежегодный «доход300тыс.₽» — чистый денежный поток без иных корректировок. При этих допущениях результаты согласуются с превышением лекционного индекса над единицей. Это не доказательство намерения преподавателя и не приравнивание MPI к IRR. Годовой шаг и денежные единицы указаны.

Тренировочные варианты авторские. Официальные формат, дата и темп контрольной не установлены. Автоматический балл проверяет ответы; свободный текст и освоение студентом этим не подтверждаются.

## Сохранность и производительность

Схема прогресса, валидатор/codec, полные snapshots и прежняя история не мигрируются заново. Номер версии условия не делает уже открывавшуюся экономическую ситуацию невиданной. Контекст помощи дополнен необязательным адресом назначения; старый навигационный контекст не восстанавливает устаревшую кнопку.

Сравнение RC/candidate выполняется одинаковым компактным протоколом: Home/T4 и стабильное числовое задание,0/1000синтетических попыток,360/1440px, сырые наблюдения и проверка введённых строк после reload. Показатель второго animation frame не является INP; cross-document CPU deltas не используются. Прежняя регрессия старта не скрывается. Без доказанного безопасного выигрыша полные проходы validProgress/codec оставлены на следующий цикл.
