## Архитектура и данные

[CurriculumRegistry](CURRICULUM_REGISTRY.md) моделирует курс, модули, уроки, разделы, компетенции, формулы, примеры, задачи, семейства и контрольные. Будущая программа не фиксируется. Синтетическая тема4 существует только в тестах; её нет в настоящем каталоге.

Публикационный статус контента внутри локальной сборки `PUBLISHED` означает прохождение внутренних source/finance/pedagogical gates; он не означает разрешение на внешний deployment. Ledger принимает конкретные ID/версии. Неизвестные ID и новые версии не получают старое approval автоматически.

Хранение остаётся локальным: ключ `cflos.progress.v1`, schema1, неизменяемые старые результаты и snapshots. Новые паспорт контрольной и самоклассификация ошибок — опциональные поля. Оценки не пересчитываются при импорте. Совместимость переноса v0.3.0→кандидат проверяется на синтетических fixtures; старая v0.3.0 не умеет интерпретировать новые задачи и timed blueprints.

## Ограничения доказательств

- NordicTech/«Задание к семинару3.xlsx»: `SOURCE_AVAILABLE_PRIVATE / CALIBRATED_WITH_STATED_LIMITS` (SHA-256 `541f041a94b5f8a71cad57aa9298e0da33e39581bfca87fbf93b5a167585654c`). Источник найден и частно проверен; прежний статус отражал неполный поиск. Workbook и его таблица не входят в public source. Неопределённое разложение D&A, точность одной налоговой строки и отсутствие графика новых инвестиций/долга сохранены как ограничения. Условная учебная модель не подменяется копией workbook.
- Фотографии реальных контрольных: `NOT_AVAILABLE`; совпадение формата и темпа с реальной КР3 не доказано. Все варианты — авторские тренировочные симуляции.
- Проверка арифметики, внутренняя экспертная рецензия и blind agent simulation не доказывают освоение студентом. `objectiveScore`, объяснение и самопроверка разделены; результат обучения остаётся `NOT_PROVEN`.
- Нет сервера, аккаунтов, облачной синхронизации, PWA и автоматической смысловой оценки текста. JSON — способ переноса между origins/устройствами.
- Физические телефоны, реальные студенты, преподавательское одобрение и новая Ubuntu CI не заявляются без соответствующих фактических проверок.
