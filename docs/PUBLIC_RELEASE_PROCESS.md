Check current reachable history and source, not only a previous audit receipt.

Dispatch the guarded workflow for that SHA with owner approval; require the exact verified Pages artifact and current policy before deployment. Release receipts and original supporting logs are maintained in the private release record to avoid exposing local paths or private evidence. GitHub Actions provides the public operational record. A receipt is evidence of its stated run, not permission for a different SHA.
